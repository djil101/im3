# Velometer Chur

Das Velometer Chur zeigt in Echtzeit, wie viele Velos von Moinz (von Nextbike) aktuell an den verschiedenen Stationen (Bahnhofplatz, Kantonsspital und Obere Au) in Chur verfügbar sind. Die Daten werden automatisch aus der API übernommen, verarbeitet und als übersichtliche Tabelle dargestellt. Zudem werden die Daten jede Stunde in unserer Datenbank gespeichert, um auf der Webseite den Durchschnittswert als Grafik anzuzeigen und die beste und schlechteste Zeit, um ein Fahrrad zu mieten, zu ermitteln.

Während der Umsetzung haben wir viel darüber gelernt, wie man externe Datenquellen einbindet, sinnvoll verarbeitet und visualisiert. Zusätzlich haben wir enorm viel über Datenbanken gelernt, wie man sie anlegt und eine Aufgabe zur Datensicherung erstellt. Wir hatten uns die Aufgaben für den Leistungsnachweis sehr gut aufgeteilt. Gleichzeitig gab es aber einige Herausforderungen: Das Pushen und Pullen auf GitHub war anfangs schwierig, da wir vermeiden wollten, dass Dateien überschrieben oder gelöscht werden. Auch das Erstellen und Darstellen der Grafik bereitete uns anfangs grosse Schwierigkeiten, bis wir nach langem Knobeln und mit der Hilfe von Jasper eine funktionierende Lösung fanden.

Unterstützt wurden wir dabei von verschiedenen Tools: GitHub Copilot sowie Claude halfen uns enorm bei der Code-Erstellung, ChatGPT lieferte nützliche Ideen und Vorschläge und Jasper war uns bei jedem Schritt eine grosse Hilfe. Bei ihm lernten wir wirklich viel.
