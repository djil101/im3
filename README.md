# Velometer Chur

Das Velometer Chur zeigt in Echtzeit, wie viele Velos von Moinz (von Nextbike) aktuell an den verschiedenen Stationen (Bahnhofplatz, Kantonsspital und Obere Au) in Chur verfügbar sind. Die Daten werden automatisch aus der API übernommen, verarbeitet und als übersichtliche Tabelle dargestellt. Zudem werden die Daten jede Stunde in unserer Datenbank gespeichert, um auf der Webseite den Durchschnittswert anzuzeigen und zusammenhängend die beste und schlechteste Zeit um ein Velo zu mieten.

Während der Umsetzung haben wir viel darüber gelernt, wie man externe Datenquellen einbindet, sinnvoll verarbeitet und visualisiert. Zusätzlich haben wir enorm viel über die Datenbank gelernt, wie man sie anlegt und eine Aufgabe zur Datensicherung erstellt. Wir hatten uns die Aufgaben für den Leistungsnachweis sehr gut aufgeteilt. Gleichzeitig gab es aber einige Herausforderungen: Das Pushen und Pullen auf GitHub war anfangs schwierig, weil wir vermeiden wollten, dass Dateien überschrieben oder gelöscht werden. Auch das Erstellen und Darstellen der Tabelle brachte uns zuerst grosse Schwierigkeiten, bis wir nach langem Kniffeln eine funktionierende Lösung fanden.

Unterstützt wurden wir dabei von verschiedenen Tools: GitHub Copilot sowie Claude halfen uns massiv bei der Code-Erstellung, ChatGPT lieferte nützliche Ideen und Vorschläge und Jasper war bei jedem Schritt eine grosse Hilfe. Bei ihm lernten wir wirklich viel.
